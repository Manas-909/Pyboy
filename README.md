# Pyboy
<img width="1100" height="872" alt="image" src="https://github.com/user-attachments/assets/4a45bad7-6fc7-4d7c-9e3e-fb277900bad8" />


Pyboy is a classic Gameboy simulator written in Pygame. It runs 2 retro games right now, pong and snake although i'm planning to port GTA 6 into this thing.
yeah that will have to wait for now, to play any current game you have to navigate to that game with A or D and press space to start the game and
press ESC if you wanna exit the game, simple.

# Installation
you can either clone this repository with ```git clone https://github.com/Manas-909/Pyboy```, navigate to the project folder, install pygame
with ```pip install pygame``` and run ```python pyboy.py``` or you can download and try it on your system from [here](https://neongs505.itch.io/pyboy).

# Was AI used?
i wouldn't say that i didn't touch AI for this project, but it is also true that AI was very, very occasionally used in this project, roughly 3 times
where i couldn't complete a function or sort something. No AI generated assets was used btw, i also stated in my commit message whenever I took
help from AI.
